# IOT-electrical-accident-recorder
An IoT-based system for monitoring electrical conditions, recording abnormal events, and improving workplace electrical safety.
IoT-Based Electrical Accident Recorder

Problem Statement

Electrical accidents can cause injuries, equipment damage, and production losses. Existing systems may not record enough information to investigate electrical faults.

Proposed Solution

Our project uses IoT technology to monitor electrical conditions, detect abnormal events, record fault details, and help improve workplace safety.

Objectives

- Monitor electrical parameters.
- Detect abnormal electrical conditions.
- Record electrical fault events.
- Help investigate accidents.
- Improve electrical safety.

Technologies Used

- IoT
- Sensors
- Microcontroller
- Data Logging

Applications

- Manufacturing industries
- Electrical maintenance teams
- Industrial safety departments

Expected Outcome

To develop a prototype that records abnormal electrical events and helps users investigate electrical accidents.

Project Status

Initial stage. Hardware selection, coding, and testing are in progress.
